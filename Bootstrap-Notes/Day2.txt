**what is container & container-fluid in bootstrap**
1.container is fixed-width size element in bootstrap. it spaces left and right margin and then appear.
2. container-fluid is full width element in bootstrap. 

**uses of container and container-fluid in bootstrap**
use of "container" is using screen size need to be adjustable every time.
use of "container-fluid" takes 100% screen width. it is used in header, footer, slider.
**for creation of normal page layout we will use container.**
