***input important attributes***
name:- it specify name
placeholder:- it provides hint of what to be filled inside input.
required:- it force the user to fill all the fields in form where required is applied.
readonly:- it provides only readable value
disabled:- it disabled the input field that will be not in used.
value:- it display value in input field that matches user input.
maxlength:- it defined a value range that can be used inside the form.
